# सोनी कोल डिपो (Soni Coal Depot) - Durg, Chhattisgarh

आधिकारिक वेबसाइट - सोनी कोल डिपो, दुर्ग (छ.ग.)
Official website for **Soni Coal Depot**, Durg, Chhattisgarh.

## विशेषताएं (Features)
- **स्थानीय ईंधन किस्में (Regional Coal Varieties)**: स्टीम कोयला (Steam Coal), इंडस्ट्रियल हार्ड कोक (Hard Coke / BP Coke), ईंट भट्ठा कोयला (Brick Kiln Slack Coal), लकड़ी कोयला (Wood Charcoal).
- **लचीला खरीद विकल्प (Flexible Sizing)**: खुला कोयला प्रति किलो (Per-Kg), 40-50kg सीलबंद बोरी, अथवा थोक ट्रैक्टर/टिपर लोड।
- **लाइव रेट कैलकुलेटर (Live Estimator)**: किलो, बोरी और थोक मात्रा का वास्तविक अनुमानित खर्च + स्थानीय ट्रांसपोर्ट भाड़ा + हमाली/पल्लेदार।
- **व्हाट्सएप ऑर्डर एकीकरण (Direct WhatsApp Ordering)**: एक क्लिक में ऑर्डर विवरण सीधे व्हाट्सएप चैट पर।
- **दुर्ग-भिलाई डिलीवरी (Regional Logistics)**: दुर्ग शहर, गंज मंडी, भिलाई सेक्टर्स, सुपेला, कुम्हारी, जामुल, धमधा व पाटन बेल्ट।

## तकनीक (Tech Stack)
- HTML5 (Semantic & SEO-ready)
- Modern Responsive CSS3 (Custom Properties, Flexbox, CSS Grid)
- Vanilla JavaScript (Dynamic pricing calculations & WhatsApp query generation)
- Google Fonts (Tiro Devanagari Hindi & Plus Jakarta Sans)
